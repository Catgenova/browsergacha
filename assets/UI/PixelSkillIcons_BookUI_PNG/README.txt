========================================
  Pixel Skill Icons & Book UI
========================================

A pixel art style skill icon and skill book UI asset pack for RPG games.


----------------------------------------
  CONTENTS
----------------------------------------

[Skill Icons] - 271 Total

Includes skill icons for 4 classes:

  Class                          Icons
  -------------------------------------
  Warrior / Berserker              57
  Mage / Sorcerer                  74
  Archer / Assassin                84
  Priest / Paladin                 56

Each icon is provided in 4 sizes:
  - 32 x 32 px
  - 64 x 64 px
  - 102 x 102 px
  - 204 x 204 px

Each icon is provided in 2 states:
  - 01_Normal   : Active state
  - 02_Disabled : Disabled state


[UI Elements] - 33 Total

All elements needed to build the skill book UI:
  - Backgrounds & Decorations (Background, Page Deco, Magic Book Image, etc.)
  - Buttons (Blue, Green, GreenBlue, Orange, PinkRed, Purple, Red, Yellow, Close)
  - Slots (Normal, Selected, Hover)
  - Bookmarks (Horizontal, Vertical)
  - Text Images (GradeUP, SkillUP)
  - Star Badges (Star, Star_Off)
  - Other UI Elements (Equip Icon, Focus Corners (LT/RT/LB/RB), Red Dot, etc.)
