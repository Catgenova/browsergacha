Archetype Bench

Archetype bench — 65 heroes at 10★ Lv 100, ungeared, 7v7 within archetype, 25 seeded sims each, 60s window, 2%/s attrition

What this measures

Every hero is dropped into the same fight in place of one ally, against and alongside a fixed cast drawn from its own archetype. The only thing that changes between runs is the hero under test — which is what makes the comparison fair rather than realistic. Nobody carries gear, so the numbers are the kit and the statline and nothing else.

The cast is fixed

Six allies and seven opponents, the median-power members of the same bucket. Both formations are full: a half-empty board silently undervalues anything that hits a row.

Judged on one axis

A back-row healer and a front-row bruiser have no business on the same leaderboard, so each bucket is ranked on the thing that bucket exists for — damage, worth or effective HP.

Everything is a rate

Most mirrors run the clock out with no winner. That is fine and expected: every column is per-second, so a fight that never resolves still measures throughput.

Seeded

The same hero replays the same fight every time, so a difference between two heroes is a difference in the heroes and not in the dice.

That last column is the finding, and no per-skill pass can move it. Base stat budgets are deliberately equal for everybody (js/data/balance.js normalises every hero to one power budget, and says so: rarity is meant to live in starting stars, level cap and summon odds, nowhere else). But the star multiplier in js/progression.js compounds 1.25× per star gained ABOVE a hero's base rarity — so a 1★ climbing to 10★ takes nine steps and a 5★ takes five. At the shared endgame that is 2.44× in favour of the cheap hero, for 45 duplicates against 35. Equal base stats times an inverted multiplier is an inverted roster, and the table above is reading that back.

Righting it is a design decision, not a tuning one, because the two rules currently contradict each other. Either rarity earns a bigger base budget (a per-shelf target in balance.js, which is the only way to reach 1.25× at equal stars and levels), or the star multiplier keys off stars alone so a 10★ is a 10★ whatever it started as — which flattens the curve rather than tilting it. Both change every hero in the game and the duplicate economy underneath them.
